5. 화면 확대 100%, 알림·메신저 끄기, 슬라이드 쇼 시작

## 1. 표지 (0:00 ~ 0:12)
안녕하세요. 제주 돌담 열네 곳을 다녀올 때마다 내 수첩의 돌벽이 채워지는 웹앱, **돌담 오늘**을 만든 ○○○입니다. [QR 가리키며] 오른쪽 QR로 지금 바로 열어 보실 수 있어요.

## 2. 기획 의도 (0:12 ~ 0:40)
제주 돌담은 바람 많은 섬이 쌓아 온 문화유산인데, 여행자에게는 그냥 지나치는 풍경이에요. 밭담, 환해장성, 방사탑이 어디 있고 무엇이 다른지 한곳에서 알기도 어렵습니다.
그래서 돌담 열네 곳을 종류별로 알려 주고, 다녀오면 수첩의 돌벽을 한 칸씩 채우게 만들었어요. 한 줄로 **"걷는 만큼 쌓이는 나만의 제주 돌담"** 입니다.

## 3. 기능 한눈에 (0:40 ~ 0:55)
기능은 여덟 가지예요. 홈, 명소와 도감, 실제 지도, 무장애와 주변 정보, 내 돌담 수첩, 바람과 돌담 3D, AI 돌담지기, 그리고 모바일과 공유입니다. 차례로 보여 드릴게요.

## 4. ① 홈 (0:55 ~ 1:10)
[홈] 제주 지도 위에 돌담 열네 곳이 종류별 색으로 표시되고, 이름표는 서로 겹치지 않게 자동으로 배치돼요. 기상청 예보로 제주시와 서귀포시의 바람과 비를 보여 주고, 날씨에 맞는 돌담도 하나 추천합니다.

## 5. ② 명소·도감 (1:10 ~ 1:25)
돌담 종류 일곱 가지 설명과 명소 열네 곳이 한 화면에 있고, 검색과 종류, 무장애 필터로 고를 수 있어요. 사진마다 출처와 라이선스를 적었고, 위치가 얼마나 정확한지는 배지로 구분했습니다.

## 6. ③ 명소 상세: 실제 지도와 실측 경로 (1:25 ~ 1:40)
명소를 누르면 실제 지도 위에 공공데이터의 실측 GPS 경로가 그려져요. 돌문화공원과 감수굴밭담길 두 곳에 실측 경로가 있고, 안내 지점과 거리, 소요 시간도 함께 나옵니다.

## 7. ④ 위성과 고도 프로필 (1:40 ~ 1:55)
[위성 버튼] 위성으로 바꾸면 밭담이 바둑판처럼 보여요. 돌문화공원에는 고도 프로필도 있어서 어디가 오르막인지 그래프로 보이고, 최고·최저·누적 상승을 알려 줍니다.

## 8. ⑤ 무장애 구간별 안내와 찾아가기 (1:55 ~ 2:10)
무장애 정보도 담았어요. 구간별로 주차장, 화장실, 휠체어 대여, 경사, 바닥 상태를 조사한 내용 그대로 보여 주고, 찾아가기는 좌표로 도착지를 지정하는 카카오맵 길찾기로 연결합니다.

## 9. ⑥ 돌문화공원 전시와 주변 장소 (2:10 ~ 2:25)
돌문화공원에서는 제주도청 오픈API로 지금 열리는 전시와 행사를 보여 줘요. 모든 명소에는 관광공사 TourAPI로 주변 관광지, 식당, 숙박 탭이 있고 지도의 번호 핀과 카드가 연결됩니다. 숙박은 등록이 적어서 반경 이십 킬로미터까지 찾고, 그렇다고 안내해요.

## 10. ⑦ 내 돌담 수첩 (2:25 ~ 2:50) ★핵심
핵심 기능입니다. [내 수첩] 도장을 찍으면 돌벽의 빈 구멍이 돌로 채워져요. 모양이 제각각인 돌 아흔여덟 개이고, 명소 하나가 일곱 개를 맡습니다. 열네 곳을 다 채우면 "돌담 장인"이 돼요.
도장은 Supabase에 저장돼서 새로고침해도 남고, 완성한 돌벽은 닉네임과 함께 이미지로 저장해 공유할 수 있습니다.

## 11. ⑧ 바람과 돌담 3D (2:50 ~ 3:15)
돌담이 왜 필요한지는 3D로 보여 드려요. [3D 화면] 기상청 오늘 풍속을 돌담에 불어 넣으면 담을 지난 바람은 주황색으로 약해지고 작물도 덜 흔들립니다. 슬라이더로 바람을 키우고 돌담을 치우면 차이가 바로 보여요. 줄어드는 비율은 원리를 보여 주는 **설명용 모형**이라고 화면에 밝혀 뒀습니다.

## 12. ⑨ AI 돌담지기 (3:15 ~ 4:05) ★시연
돌담지기는 오른쪽 아래의 작은 팝업이에요. 질문하면 Claude가 도구 여섯 개 중 필요한 것을 스스로 골라 차례로 호출합니다.
[시연: 돌담지기에 "오늘 바람 센데 갈 만한 돌담 어디야?"] 날씨를 조회하고, 명소를 찾고, 필요하면 상세까지 부르고 있어요. [답이 나오면] 답변 위에 어떤 도구를 몇 건 불렀는지 그대로 보입니다. 근거가 없는 내용은 지어내지 않도록 지시해 뒀어요.
(시연 20~40초. 끝나면 슬라이드 쇼로 복귀)

## 13. 공공데이터와 시스템 구조 (4:05 ~ 4:25)
데이터는 기상청, 에어코리아, 한국관광공사, 제주도청, 무장애여행정보 등을 실제로 호출해요. 브라우저에는 Supabase 공개 키만 있고, 모든 공공 API와 Claude 호출은 Vercel 서버 함수를 거칩니다. 한도나 장애에 대비해 캐시와 대체 값을 두었고, 대체 값은 화면에 추정이라고 밝혀요.

## 14. 믿을 수 있게 만든 장치 (4:25 ~ 4:40)
모든 사진에 출처를 적었고, 위치는 좌표 출처를 배지로 구분해요. 설명용 모형과 추정값은 그렇다고 화면에 밝혔고, 키는 서버에만 있습니다. 장애에는 캐시와 한국어 오류 안내, 다시 시도 버튼으로 대비했어요.

## 15. 모바일과 공유 (4:40 ~ 4:55)
여행 중에는 휴대폰으로 쓰니까 작은 화면을 먼저 확인했어요. 이름표를 키웠고, 3D 화면은 따로 불러와서 첫 화면을 절반으로 줄였습니다. 주소를 공유하면 제목·설명·이미지가 보이는 미리보기와 QR도 만들었어요.

## 16. 아쉬운 점과 다음 계획 (4:55 ~ 5:10)
아쉬운 점은 근사 위치 세 곳, 설명용 바람 모형, 숙박 정보 부족, 실습용 보안 정책입니다. 다음에는 제주어와 설화를 연결하고, 버스 정보와 로그인, 대화 기록 저장을 붙이겠습니다.

## 17. 마무리 (5:10 ~ 5:15)
걷는 만큼 쌓이는 나만의 제주 돌담, 돌담 오늘이었습니다. 감사합니다. 질문 받겠습니다.

## 예상 질문과 답 (해당 슬라이드로 돌아가 설명)

**Q1. API 키가 노출되지 않나요?** (13번)
키는 Vercel 서버 환경변수에만 있고 브라우저에는 Supabase 공개(anon) 키만 들어갑니다. 빌드 결과물과 GitHub 기록 전체에서 키 문자열이 없는 것을 확인했고, `.env.local`은 저장소에 올라가지 않습니다.

**Q2. 바람이 줄어드는 수치는 실측인가요?** (11번)
아닙니다. 원리를 보여 주는 설명용 모형이고 화면에도 적었습니다. 풍속은 기상청 실제 예보이고, 담 뒤 감소 비율만 모형이에요.

**Q3. 돌담지기가 거짓말하면?** (12번, 14번)
① 시스템 지시로 도구 결과에 없는 사실을 말하지 않게 했고, ② 호출 내역이 화면에 보여서 근거를 확인할 수 있으며, ③ 미세먼지가 추정이면 "추정"이라고 밝히게 했습니다.

**Q4. 에이전트가 도구를 여러 번 부르는 걸 확인했나요?** (12번)
가짜 Claude 서버로 처음부터 끝까지 돌려 봤습니다. 한 번에 3개, 다음 차례에 4개를 부르고, 없는 명소 id는 오류로 안전하게 처리했어요. 여섯 개 도구는 실제 공공 API 데이터로 응답했습니다. 실제 Claude 응답은 [키 상태에 따라: 화면에서 보신 대로입니다 / 키 교체 후 확인합니다].

**Q5. Supabase 보안은요?** (16번)
실습용 정책이라 누구나 읽고 쓸 수 있습니다. 실서비스라면 Supabase Auth로 로그인하고 본인 행만 다루게 바꿔야 해요. 다음 계획에 넣었습니다.

**Q6. 위치가 정확한가요?** (5번, 6번, 14번)
좌표 출처를 배지로 구분했습니다. 실측 경로 2곳, 한국관광공사 좌표 7곳, 위키백과 1곳, OpenStreetMap 1곳이고, 한담·김녕·우도 3곳은 점 하나로 정하기 어려워 "근사 위치"입니다.

**Q7. 사진 저작권은요?** (5번, 14번)
한국관광공사 공공누리 1·3유형과 위키미디어 CC BY-SA 사진만 썼고 모든 사진 아래에 출처와 라이선스를 적었어요. 변경 금지(3유형) 사진은 크기만 줄이고 자르거나 합성하지 않았습니다.

**Q8. 왜 날씨 추천 앱으로 안 했나요?** (2번)
날씨 추천은 흔하고 오래 쓰이지 않을 것 같아서, 걷는 만큼 쌓이는 수집형 경험으로 바꿨습니다. 날씨는 홈, 바람과 돌담, 돌담지기의 근거로 남겼어요.

**Q9. 모바일에서도 되나요?** (15번)
네. 작은 화면에서 이름표를 키우고, 돌담지기는 하단 시트로 열립니다.

**Q10. 다음에 무엇을 더 하나요?** (16번)
제주어와 설화를 연결하고, 버스 정보로 저상버스 찾아가기를 붙이고, 로그인과 대화 기록 저장을 추가하겠습니다.

**Q11. 무엇이 가장 어려웠나요?** (10번)
모양이 제각각인 돌을 틈 없이 맞물려 채우는 돌벽입니다. 보로노이 분할로 돌 98개를 늘 같은 모양으로 만들고, 명소 하나를 이웃한 돌 일곱 개로 묶었어요.

**Q12. 무장애 정보는 어디서 가져왔나요?** (8번)
제주 무장애여행정보 공공데이터의 실측 경로와 구간별 조사 내용입니다. 현재 감수굴밭담길과 돌문화공원 두 곳이 해당돼요.
