# 발표 대본 — 돌담 오늘 (17장, 모든 기능 소개)

- 부록 없이 **모든 기능을 본 발표에서 소개**해요. 17장 × 평균 17초 ≈ **5분**
- **3분으로 줄여야 할 때**: 아래 "3분 압축" 표대로 ★ 슬라이드만 말하고 나머지는 넘기세요
- `[ ]` = 행동 지시. 슬라이드 노트(발표자 보기)에도 같은 요지가 있어요
- 말하는 속도: 1분에 약 300자

## 발표 전 체크리스트 (5분 전)
1. 배포 주소가 열리는지 확인 → https://doldam-today-jeju-project.vercel.app
2. **돌담지기에 질문 1번 해 보기**: 답이 나오고 호출 내역이 보이는지 (안 되면 아래 '시연 대안')
3. 바람과 돌담(3D)을 미리 한 번 열어 두기 (처음 열 때 몇 초 걸림)
4. 닉네임을 정하고 도장 2~3개 찍어 두기 → 내 수첩에서 돌벽이 채워진 상태로 시작
5. 홈의 "걷기 좋은 때" 패널이 뜨는지 확인 (기상청 예보를 받아야 해서 인터넷 필요)
6. 화면 확대 100%, 알림·메신저 끄기, 슬라이드 쇼 시작

## 1. 표지 (0:00 ~ 0:12)
안녕하세요. 제주 돌담 열네 곳을 다녀올 때마다 내 수첩의 돌벽이 채워지는 웹앱, **돌담 오늘**을 만든 박지환입니다.

## 2. 기획 의도 (0:12 ~ 0:40)
제주 돌담은 바람 많은 섬이 쌓아 온 문화유산인데, 여행자에게는 그냥 지나치는 풍경이에요. 밭담, 환해장성, 방사탑이 어디 있고 무엇이 다른지 한곳에서 알기도 어렵습니다.
그래서 돌담 열네 곳을 종류별로 알려 주고, 다녀오면 수첩의 돌벽을 한 칸씩 채우게 만들었어요. 한 줄로 **"걷는 만큼 쌓이는 나만의 제주 돌담"** 입니다.

## 3. 기능 한눈에 (0:40 ~ 0:55)
기능은 여덟 영역이에요. 걷기 좋은 때, 명소와 도감, 실제 지도, 주변 정보(관광지·식당·숙박·축제), 내 돌담 수첩, 바람과 돌담 3D, AI 돌담지기, 그리고 모바일과 공유입니다. 차례로 보여 드릴게요.

## 4. 홈 (0:55 ~ 1:08)
[홈] 제주 지도 위에 돌담 열네 곳이 종류별 색으로 표시돼요. 위쪽 날씨 칩은 기상청 예보로 제주시와 서귀포시의 바람과 비, 그리고 내일의 걷기 수준까지 알려 줍니다.

## 5. 걷기 좋은 때 (1:08 ~ 1:30) ★
[걷기 좋은 때 패널] 날씨를 그냥 보여 주는 대신 걷기 좋은 시간을 알려 드려요. 오늘 남은 시간과 내일을 한 시간 단위로 초록, 노랑, 빨강 막대로 보여 주고, 가장 길게 이어지는 좋은 시간을 한 줄로 알려 줍니다. 기온과 습도, 바람으로 체감온도를 계산해서 옷차림도 한 줄로 제안하고, 일몰 시각과 자외선도 함께 보여 줘요.
비가 올 것 같으면 아래의 **비 오는 날 대안 코스**가 강조돼요. 실내 전시가 있는 제주돌문화공원과 지금 열리는 전시, 근처 식당을 이어서 추천합니다.

## 6. 명소·도감 (1:30 ~ 1:42)
돌담 종류 일곱 가지 설명과 명소 열네 곳이 한 화면에 있고, 검색과 종류, 무장애 필터로 고를 수 있어요. 위치가 얼마나 정확한지는 배지로 구분했습니다.

## 7. 명소 상세: 실제 지도와 실측 경로 (1:42 ~ 1:55)
명소를 누르면 실제 지도 위에 공공데이터의 실측 GPS 경로가 그려져요. 돌문화공원과 감수굴밭담길 두 곳에 실측 경로가 있고, 안내 지점과 거리, 소요 시간도 함께 나옵니다.

## 8. 위성과 고도 프로필 (1:55 ~ 2:07)
돌문화공원에는 고도 프로필도 있어서 어디가 오르막인지 그래프로 보이고, 최고·최저·누적 상승을 알려 줍니다.

## 9. 무장애 구간별 안내와 찾아가기 (2:07 ~ 2:19)
무장애 정보도 담았어요. 구간별로 주차장, 화장실, 휠체어 대여, 경사, 바닥 상태를 조사한 내용 그대로 보여 주고, 찾아가기는 좌표로 도착지를 지정하는 카카오맵 길찾기로 연결합니다.

## 10. 숙박 보강과 축제·행사 (2:19 ~ 2:34)
관광공사의 데이터를 받아 명소와의 거리로 걸러 보여 주는 방식으로 바꿨고, 별방진 기준으로 한 곳에서 여덟 곳이 되었습니다. 축제·행사 탭에서는 진행 중이거나 예정인 제주 행사를 기간과 거리와 함께 보여 줍니다.

## 11. 돌문화공원 전시와 주변 장소 (2:34 ~ 2:46)
돌문화공원에서는 제주도청 오픈API로 지금 열리는 전시를 보여 줘요. 모든 명소에는 주변 관광지와 식당 탭이 있고, 지도의 번호 핀과 카드가 연결되며 누르면 카카오맵으로 열립니다.

## 12. 내 돌담 수첩 (2:46 ~ 3:12) ★핵심
 [내 수첩] 도장을 찍으면 돌벽의 빈 구멍이 돌로 채워져요. 모양이 제각각인 돌 아흔여덟 개이고, 명소 하나가 일곱 개를 맡습니다. 열네 곳을 다 채우면 "돌담 장인"이 돼요.
도장은 Supabase에 저장돼서 새로고침해도 남고, 완성한 돌벽은 닉네임과 함께 이미지로 저장해 공유할 수 있습니다. 아래 "아직 안 가 본 곳" 카드에서는 **도장 찍기** 버튼으로 바로 돌벽을 채울 수도 있어요.

## 13. 바람과 돌담 3D (3:12 ~ 3:38) ★
돌담이 왜 필요한지는 3D로 보여 드려요. [3D 화면] 기상청 오늘 풍속을 돌담에 불어 넣으면 담을 지난 바람은 주황색으로 약해지고 작물도 덜 흔들립니다. 슬라이더로 바람을 키우고 돌담을 치우면 차이가 바로 보여요. 줄어드는 비율은 원리를 보여 주는 **설명용 모형**이라고 화면에 밝혀 뒀습니다.

## 14. AI 돌담지기 (3:38 ~ 4:28) ★시연
돌담지기는 오른쪽 아래의 작은 팝업이에요. 질문하면 AI(Claude 또는 Gemini)가 도구 여섯 개 중 필요한 것을 스스로 골라 차례로 호출합니다.
[시연: 돌담지기에 "오늘 바람 센데 갈 만한 돌담 어디야?"] 날씨를 조회하고, 명소를 찾고, 필요하면 상세까지 부르고 있어요. [답이 나오면] 답변 위에 어떤 도구를 몇 건 불렀는지 그대로 보입니다. 근거가 없는 내용은 지어내지 않도록 지시해 뒀어요.
그리고 **대화는 닉네임별로 Supabase에 저장**돼요. [팝업을 닫았다 다시 열거나 새로고침] 이렇게 다시 열면 이전 대화가 "이전 대화 ○개를 불러왔어요"로 이어집니다.
(시연 30~50초. 끝나면 슬라이드 쇼로 복귀)

## 15. 공공데이터와 시스템 구조 (4:28 ~ 4:46)
데이터는 기상청, 에어코리아, 한국관광공사, 제주도청, 무장애여행정보에 일몰·자외선 Open-Meteo까지 실제로 호출해요. 브라우저에는 Supabase 공개 키만 있고, 모든 공공 API와 Claude 호출은 Vercel 서버 함수를 거칩니다. 한도나 장애에 대비해 캐시와 대체 값을 두었고, 대체 값은 화면에 추정이라고 밝혀요.

## 16. 모바일과 공유 (4:46 ~ 4:58)
여행 중에는 휴대폰으로 쓰니까 작은 화면을 먼저 확인했어요. 3D 화면은 따로 불러와서 첫 화면을 절반으로 줄였고, 주소를 공유하면 제목·설명·이미지가 보이는 미리보기와 QR도 만들었어요.

## 17. 마무리 (4:58 ~ 5:05)
걷는 만큼 쌓이는 나만의 제주 돌담, 돌담 오늘이었습니다. 질문 받겠습니다.

## 예상 질문과 답 (해당 슬라이드로 돌아가 설명)

**Q1. API 키가 노출되지 않나요?** (15번)
키는 Vercel 서버 환경변수에만 있고 브라우저에는 Supabase 공개(anon) 키만 들어갑니다. 빌드 결과물과 GitHub 기록 전체에서 키 문자열이 없는 것을 확인했고, `.env.local`은 저장소에 올라가지 않습니다.

**Q2. 바람이 줄어드는 수치는 실측인가요?** (13번)
아닙니다. 원리를 보여 주는 설명용 모형이고 화면에도 적었습니다. 풍속은 기상청 실제 예보이고, 담 뒤 감소 비율만 모형이에요.

**Q3. 돌담지기가 거짓말하면?** (14번)
① 시스템 지시로 도구 결과에 없는 사실을 말하지 않게 했고, ② 호출 내역이 화면에 보여서 근거를 확인할 수 있으며, ③ 미세먼지가 추정이면 "추정"이라고 밝히게 했습니다.

**Q4. 에이전트가 도구를 여러 번 부르는 걸 확인했나요?** (14번)
가짜 Claude 서버로 처음부터 끝까지 돌려 봤습니다. 한 번에 3개, 다음 차례에 4개를 부르고, 없는 명소 id는 오류로 안전하게 처리했어요. 여섯 개 도구는 실제 공공 API 데이터로 응답했습니다. 실제 Claude 응답은 [키 상태에 따라: 화면에서 보신 대로입니다 / 키 교체 후 확인합니다].

**Q5. Supabase 보안은요? 대화 기록은 안전한가요?** (14번)
실습용 정책이라 누구나 읽고 쓸 수 있습니다. 대화는 닉네임별로 저장하고, 닉네임이 없으면 이 브라우저 전용 번호를 붙여 다른 사람과 섞이지 않게 했지만, 같은 닉네임을 쓰면 같은 기록이 보입니다. 실서비스라면 전용 테이블과 로그인으로 본인 기록만 보게 바꿔야 해요.

**Q6. 위치가 정확한가요?** (6번, 7번)
좌표 출처를 배지로 구분했습니다. 실측 경로 2곳, 한국관광공사 좌표 7곳, 위키백과 1곳, OpenStreetMap 1곳이고, 한담·김녕·우도 3곳은 점 하나로 정하기 어려워 "근사 위치"입니다.

**Q7. 사진 저작권은요?** (README의 사진 출처 설명)
한국관광공사 공공누리 1·3유형과 위키미디어 CC BY-SA 사진만 썼고 모든 사진 아래에 출처와 라이선스를 적었어요. 변경 금지(3유형) 사진은 크기만 줄이고 자르거나 합성하지 않았습니다.

**Q8. 왜 날씨 추천 앱으로 안 했나요?** (2번, 5번)
날씨 추천은 흔해서, 걷는 만큼 쌓이는 수집형 경험으로 바꿨습니다. 대신 날씨는 "걷기 좋은 때"처럼 행동으로 이어지게 했어요. 시간대별 막대, 체감온도와 옷차림, 일몰, 비 오는 날 대안 코스가 그 예입니다.

**Q9. 모바일에서도 되나요?** (16번)
네. 작은 화면에서 이름표를 키우고, 돌담지기는 하단 시트로 열립니다.

**Q10. 다음에 무엇을 더 하나요?**
제주어와 설화를 연결하고, 버스 정보로 저상버스 찾아가기를 붙이고, 로그인과 대화 기록 전용 테이블로 본인 기록만 보이게 하겠습니다.

**Q11. 무엇이 가장 어려웠나요?** (12번, 10번)
모양이 제각각인 돌을 틈 없이 맞물려 채우는 돌벽입니다. 보로노이 분할로 돌 98개를 늘 같은 모양으로 만들고, 명소 하나를 이웃한 돌 일곱 개로 묶었어요. 숙박 데이터가 비어 있던 문제를 API 방식을 바꿔 풀기도 했습니다.

**Q12. 무장애 정보는 어디서 가져왔나요?** (9번)
제주 무장애여행정보 공공데이터의 실측 경로와 구간별 조사 내용입니다. 현재 감수굴밭담길과 돌문화공원 두 곳이 해당돼요.

**Q13. 체감온도는 정확한가요?** (5번)
기온, 습도, 풍속으로 계산한 추정값입니다. 화면에도 기온을 함께 적었고, 실측 체감온도가 아니라 옷차림 안내용입니다.

**Q14. 일몰·자외선은 어디서 가져오나요?** (5번)
Open-Meteo의 무료 API입니다. 키가 필요 없고 서버 함수를 거쳐 가져와 1시간 캐시합니다.
