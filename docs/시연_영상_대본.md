| 녹화 후 | 시연으로 찍은 도장은 내 수첩에서 지워도 돼요 |

## 장면별 대본 (총 약 2분)

### 장면 1. 홈 (0:00 ~ 0:12)
- **화면**: 홈. 돌담 지도의 색 이름표 → 오늘 날씨 칩
- **말**: "제주 돌담 열네 곳을 다녀올 때마다 돌벽이 채워지는 웹앱, 돌담 오늘입니다. 돌담 종류마다 색이 달라서 이름이 겹치지 않고 한눈에 보여요. 오늘 제주시와 서귀포시의 바람과 비도 알려 줍니다."
- **동작**: 지도 이름표 위에 마우스를 천천히 올리기

### 장면 2. 명소·도감 (0:12 ~ 0:25)
- **화면**: 상단 메뉴 '명소·도감' → 카드 목록
- **말**: "명소와 도감에서는 돌담 종류 설명과 명소 열네 곳을 함께 봅니다. 사진마다 출처와 라이선스가 있고, 위치가 얼마나 정확한지는 배지로 구분했어요."
- **동작**: 종류 칩(밭담) 한 번 눌러 설명 카드 보여 주기 → 카드 하나의 '관광공사 좌표' 배지 가리키기

### 장면 2-1. 걷기 좋은 때 (홈 아래로 스크롤)
- **말**: "시간대별 걷기 수준을 색 막대로 보여 주고, 가장 좋은 시간과 체감온도 옷차림, 일몰과 자외선을 알려 줘요. 내일 탭도 있고, 비가 오면 돌문화공원 실내 코스가 강조됩니다."
- **동작**: 오늘 → 내일 탭 → 서귀포시 탭 눌러 보기

### 장면 3. 명소 상세와 실제 지도 (0:25 ~ 0:45)
- **화면**: 감수굴밭담길 카드 클릭 → 상세
- **말**: "감수굴밭담길입니다. 실제 지도 위에 공공데이터 실측 경로가 그려지고, 선 색은 고도예요. 위성으로 바꾸면 밭담이 바둑판처럼 보입니다."
- **동작**: 오른쪽 위 '위성' 선택 → 3초 보여 주기 → 다시 '지도' → 아래로 내려 주변 식당·숙박 탭 한 번 누르기

### 장면 3-1. 숙박과 축제 (상세 페이지 아래 탭)
- **말**: "주변 숙박은 제주 숙박 이백열한 곳에서 가까운 순으로, 축제·행사는 진행 중과 예정을 기간과 거리로 보여 줍니다."
- **동작**: '주변 숙박' 탭 → '축제·행사' 탭

### 장면 4. 도장과 돌벽 수첩 (0:45 ~ 1:10)
- **화면**: 상단 '돌담 도장' 클릭 → 메뉴 '내 수첩'
- **말**: "도장을 찍으면 내 수첩의 돌벽에서 빈 구멍이 돌로 채워집니다. 모양이 제각각인 돌 아흔여덟 개이고, 명소 하나가 일곱 개를 맡아요. 도장은 Supabase에 저장되니까 새로고침해도 남습니다."
- **동작**: 돌이 튀어 오르는 장면 → **F5 새로고침** 후에도 그대로인 것 보여 주기 → '이미지로 저장' 클릭

### 장면 5. 바람과 돌담 3D (1:10 ~ 1:35)
- **화면**: 메뉴 '바람과 돌담'
- **말**: "기상청의 오늘 풍속을 3D 돌담에 불어 넣었어요. 담을 지난 바람은 주황색으로 약해지고, 담 뒤 작물은 덜 흔들립니다. 이 비율은 원리를 보여 주는 설명용 모형입니다."
- **동작**: 마우스로 돌리기 → 바람 세기 슬라이더를 오른쪽으로 → '돌담 치우기' 눌러 비교

### 장면 6. 돌담지기 (1:35 ~ 2:00)
- **화면**: 오른쪽 아래 '돌담지기에게 묻기'
- **말**: "AI 돌담지기에게 물어볼게요. 오늘 바람 센데 갈 만한 돌담 어디야? — Claude가 도구를 스스로 골라 날씨를 조회하고, 명소를 검색한 뒤 답합니다. 답변 위에 어떤 도구를 몇 건 불렀는지 그대로 보여요."
- **동작**: 예시 질문을 누르거나 직접 입력 → 답이 올 때까지 기다리기 → 호출 내역 목록을 마우스로 가리키기 → **F5 새로고침 후 팝업을 다시 열어 "이전 대화를 불러왔어요"** 보여 주기(대화 기록 저장)
- **답이 안 나올 때**: 이 장면은 자르고 아래 '대안 자막'을 넣기 (가짜 화면 금지)
  - 대안 자막: "돌담지기는 도구 6개를 스스로 골라 호출합니다. (키 갱신 중이라 답변 화면은 생략)"

### 장면 7. 마무리 (2:00 ~ 2:08)
- **화면**: 홈 또는 QR 슬라이드
- **말**: "걷는 만큼 쌓이는 나만의 제주 돌담. 감사합니다."
