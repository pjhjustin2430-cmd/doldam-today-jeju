> **자동 생성 영상**(배포 화면 캡처 + 자막 + 음성, 약 4분 13초)이 `3_시연영상_초안(자동생성).mp4`에 있어요. 아래 15장면과 같은 순서예요.
> 직접 녹화한 영상이 있으면 그것을 제출하고, 없으면 자동 생성본을 쓰세요. 이 대본은 직접 녹화할 때 따라 하면 돼요.
> 돌담지기는 **구조만 설명**해요(가짜 답변 화면은 쓰지 않아요).

### 돌담지기 장면(13)을 직접 시연하고 싶을 때
- Claude 키가 유효하면: 예시 질문을 눌러 답이 나오는 것을 보여 주고, **F5 후 팝업을 다시 열어 "이전 대화를 불러왔어요"**까지 보여 주세요.
- 키가 안 되면: 팝업의 **도구 6개 목록**만 보여 주며 "구조만 설명드립니다"라고 말하세요. 가짜 답변 화면은 쓰지 마세요.
