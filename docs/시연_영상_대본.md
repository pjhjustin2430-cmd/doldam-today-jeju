# 시연 영상 대본 (1분 30초)

녹화: `Win + Alt + R`(Xbox Game Bar) 또는 OBS. 브라우저 창 1280x720 이상, 북마크 줄·알림 끄기.
시작 주소: https://doldam-today-jeju-project.vercel.app
준비: 바람과 돌담(3D)을 미리 한 번 열어 두기 · 닉네임을 정해 두기 · 돌담지기 질문을 미리 한 번 해 보고 답이 나오는지 확인

| 시간 | 화면 | 말할 내용 |
|---|---|---|
| 0:00~0:10 | 홈 (돌담 지도) | "제주 돌담 14곳을 다녀올 때마다 돌벽이 채워지는 돌담 오늘입니다. 종류마다 색이 달라요." |
| 0:10~0:25 | 지도에서 '감수굴' 클릭 → 상세 | "실제 지도 위에 공공데이터 실측 경로가 고도 색으로 보여요." 위성 버튼 눌러 밭담 보여 주기 |
| 0:25~0:45 | 상세에서 '돌담 도장' → 내 수첩 | "도장을 찍으면 돌벽의 빈 구멍이 돌로 채워집니다." 돌이 튀어 오르는 장면 → 새로고침해도 남는 것 보여 주기 → '이미지로 저장' |
| 0:45~1:05 | 바람과 돌담 | "기상청 오늘 풍속을 3D 돌담에 불어 넣었어요. 담 뒤에서 바람이 약해집니다." 마우스로 돌리기 → 슬라이더 올리기 → 돌담 치우기 |
| 1:05~1:25 | 돌담지기 팝업 | 질문: "오늘 바람 센데 갈 만한 돌담 어디야?" → "AI가 날씨·명소 도구를 스스로 골라 호출했고, 호출 내역이 답 위에 보입니다." |
| 1:25~1:30 | 홈 | "감사합니다." |

## 체크
- 돌담지기가 답하려면 Claude 키가 유효해야 해요. 홈 아래 "동작 체크"에서 `Claude 키 사용 가능`이 보이면 OK
- 시연용으로 찍은 도장은 녹화 후 내 수첩에서 지워도 돼요
