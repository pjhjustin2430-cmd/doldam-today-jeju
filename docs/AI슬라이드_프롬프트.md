## [짧은 버전] (그대로 복사)

제주 돌담 웹앱 "돌담 오늘"의 3분 발표 슬라이드를 만들어 주세요. 한국어, 16:9, 슬라이드 10장 안팎.

주제: 제주 돌담 14곳을 다녀올 때마다 내 수첩의 돌벽이 한 칸씩 채워지는 웹앱. 한 줄 요약은 "걷는 만큼 쌓이는 나만의 제주 돌담".

구성:
1. 표지: 돌담 오늘, 제주대 청년도약 부트캠프 1기 개인 과제, 배포 주소 QR
2. 기획 의도: 돌담은 바람 많은 섬이 쌓은 문화유산인데 여행자는 그냥 지나친다 → 종류별로 알려 주고 다녀오면 돌벽이 채워지게 했다
3. 기능 한눈에: 홈 지도, 명소·도감, 실제 지도(실측 경로·위성), 무장애·주변 정보, 내 돌담 수첩, 바람과 돌담 3D, AI 돌담지기, 모바일·공유
4. 홈과 도감: 종류별 색 돌담 지도, 오늘 날씨, 돌담 종류 7가지와 명소 14곳, 사진 출처와 위치 정확도 배지
5. 실제 지도: 공공데이터 실측 경로(고도 색), 위성 전환, 고도 프로필, 무장애 구간별 안내
6. 내 돌담 수첩(핵심): 도장을 찍으면 모양이 제각각인 돌 98개 중 7개가 채워짐, 14곳 완성 시 "돌담 장인", Supabase 저장, 이미지로 공유
7. 바람과 돌담 3D: 기상청 오늘 풍속을 3D 돌담에 불어 넣으면 담 뒤에서 바람이 약해짐(설명용 모형)
8. AI 돌담지기: Claude가 도구 6개(명소 검색, 상세, 날씨, 미세먼지, 주변 장소, 전시)를 골라 호출하고 호출 내역을 화면에 표시
9. 데이터와 보안: 기상청·에어코리아·한국관광공사·제주도청·무장애여행정보, 키는 서버에만, 추정값은 "추정"으로 표시
10. 마무리: 아쉬운 점(근사 위치 3곳) · 다음 계획(제주어·설화·버스) · 감사합니다 + QR

## [상세 버전] (슬라이드별 문구까지 정해 주고 싶을 때)

**1. 표지** — 제목 "돌담 오늘" / 부제 "걷는 만큼 쌓이는 나만의 제주 돌담" / 제주대 청년도약 부트캠프 1기 · 개인 과제 / QR(배포 주소)

**2. 기획 의도** — 문제: 밭담·환해장성·방사탑이 어디에 있고 무엇이 다른지 한곳에서 알기 어렵다. 해결: 14곳을 종류별로 알려 주고 다녀오면 수첩 돌벽을 채운다. 대상: 제주를 걷는 여행자, 휠체어·유아차 이동자.

**3. 기능 8가지** — ① 홈(종류별 색 지도·오늘 날씨) ② 명소·도감 ③ 실제 지도(실측 경로·위성) ④ 무장애·주변 정보 ⑤ 내 돌담 수첩 ⑥ 바람과 돌담 3D ⑦ AI 돌담지기 ⑧ 모바일·공유

**4. 홈** — 돌담 종류 7가지(밭담·환해장성·진성·마을 돌담·방사탑·돌염전·돌문화공원)를 색으로 구분, 이름표가 겹치지 않게 자동 배치, 기상청 예보로 제주시·서귀포시 바람·강수 표시

**5. 명소·도감** — 종류 설명과 명소 14곳, 이름·지역 검색, 종류·무장애 필터, 모든 사진 아래 출처·라이선스, 위치 정확도 배지(실측 경로·관광공사 좌표·위키백과·지도 데이터·근사 위치)

**6. 실제 지도** — 제주 무장애여행정보의 GPS 경로를 OpenStreetMap 위에 표시, 감수굴밭담길은 선 색이 고도, 위성으로 바꾸면 밭담이 바둑판처럼 보임

**7. 무장애·주변** — 구간별 접근성(주차장·화장실·휠체어 대여·경사·바닥), 카카오맵 길찾기, 돌문화공원 전시(제주도청 오픈API), 주변 관광지·식당·숙박(한국관광공사 TourAPI, 숙박은 반경 20km)

**8. 내 돌담 수첩** — 도장 → 돌 7개 채움(돌 98개) → 단계: 돌 줍는 여행자 · 담 쌓는 견습생 · 돌담 숙련자 · 돌담 장인 → Supabase 저장(새로고침해도 유지) → 닉네임·단계가 적힌 이미지로 저장·공유

**9. 바람과 돌담 3D** — Three.js, 기상청 오늘 풍속 연동, 담 뒤에서 바람이 주황색으로 약해지고 작물이 덜 흔들림, 슬라이더와 "돌담 치우기"로 비교, 비율은 설명용 모형(실측 아님)

**10. AI 돌담지기** — 오른쪽 아래 팝업, Claude가 도구 6개 중 필요한 것을 스스로 골라 여러 번 호출, 호출한 도구와 결과 건수를 답 위에 표시, 근거 없는 답은 하지 않도록 지시

**11. 공공데이터·구조** — 기상청 단기예보, 에어코리아(한도 초과 시 Open-Meteo 추정 + "추정" 표시), 한국관광공사 TourAPI, 제주도청 오픈API, 제주 무장애여행정보 / 브라우저 → Vercel 서버 함수 → 외부 API, 브라우저 → Supabase

**12. 믿을 수 있게** — 사진 출처 표시, 위치 배지, 설명용 모형·추정 표시, 키는 서버 환경변수에만, 캐시와 한국어 오류 안내

**13. 모바일·공유** — 작은 화면 대응, 3D 화면 따로 불러오기(첫 화면 JS 절반), 공유 미리보기(OG)와 QR

**14. 아쉬운 점·다음 계획** — 근사 위치 3곳(한담·김녕·우도), 바람 모형, 숙박 정보 적음, Supabase 정책이 실습용 / 다음: 제주어·설화·신화, 버스 정보, 로그인, 대화 기록 저장

**15. 마무리** — "걷는 만큼 쌓이는 나만의 제주 돌담" · 감사합니다 · QR · 배포·GitHub 주소
